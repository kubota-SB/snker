# Air Jordan 1 Archive v4

GitHub Pages では、このフォルダ内のファイルを同じ階層にアップロードしてください。

## v4 の主な変更
- 価格チャートを日付ベースの価格推移表示へ変更（SNKRDUNKで日付付き履歴を取得できた場合）
- StockXは市場指標を時系列に見せかけず、過去12か月/3か月の価格レンジとして表示
- チャート表示後も「価格情報を取得しています…」が残る不具合を修正
- サイズ/新品中古変更時は以前の通信をキャンセルし、最新選択だけを描画
- SNKRDUNKの記事リンク/未登録リンクを商品番号ベースの商品ページへ補正
- 選択サイズで履歴が取れない場合は全サイズの公開データをフォールバック表示（注記あり）
- CSS/JS/JSONに v=4 を付け、GitHub Pages更新時の古いキャッシュを回避

## 価格取得について
GitHub Pagesは静的サイトなので、外部サイトのCORS・動的レンダリング・アクセス制限の影響を受けます。
そのため公開ページからの取得を100%保証することはできません。確実性を上げるには、許可された公式/契約APIまたは自分のバックエンドで価格データを取得・キャッシュし、フロント側はそのJSONだけを読む構成が必要です。
