# Air Jordan 1 Archive v5

GitHub Pages 用の静的サイトです。

## ファイル
- index.html
- snker.html
- snker.css
- snker.js
- sneakers.json

## v5 の主な修正
- 商品詳細を開いた時点で価格チャートを自動取得
- 初期サイズを「全サイズ」に変更
- 現在価格しか取得できない場合も、履歴と誤認しない「現在価格」チャートを表示
- サイズ変更時は以前のチャート・価格を即クリアして再取得
- 選択サイズのデータを確認できなかった場合、全サイズ価格をそのサイズの価格として表示しない
- SNKRDUNK の公式相場ページ `/sales-histories` へのリンクを使用
- ローディング表示が取得後に残らないよう状態管理を強化

## 重要
GitHub Pages は静的ホスティングのため、StockX / SNKRDUNK の動的なサイズ別価格・履歴を 100% 取得することはできません。確実なサイズ別価格をサイト内に表示するには、認証済み API または自前のバックエンドが必要です。
